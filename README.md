Iris Multi-Class Classification Benchmark

Project Overview

A multi-class classification project using the Iris flower dataset to compare Logistic Regression and Decision Tree algorithms.

Dataset

- Total samples: 150
- Features: 4
- Classes: Setosa, Versicolor, Virginica
- Training samples: 120
- Testing samples: 30

Models

1. Logistic Regression
2. Decision Tree Classifier

Methodology

- Data loading and exploration
- Feature and target separation
- 80/20 train-test split
- StandardScaler for Logistic Regression
- Model training and prediction
- Evaluation using Accuracy, Precision, Recall and F1-score
- Confusion matrix visualization
- Benchmark comparison

Evaluation Results

| Metric | Logistic Regression | Decision Tree |
| --- | ---: | ---: |
| Accuracy | 93.33% | 93.33% |
| Precision | 93.33% | 93.33% |
| Recall | 93.33% | 93.33% |
| F1-Score | 93.33% | 93.33% |

Both models correctly classified 28 out of 30 test samples.
